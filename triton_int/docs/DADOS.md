# Data in the International Edition (INT): what it carries, where it comes from and what to supply

Version 0.1.0, 24/10/2026. This document describes every dataset that ships with the edition: what it is, its source (URL and date), licence, coverage, resolution, period, treatment of gaps, quality, size, how the program loads it and how to reproduce it. Every figure was read from a file of the repository; where the repository holds no information, the text says "not verified".

Sizes are in MiB (1 MiB = 1,048,576 bytes, the unit of GitHub's 50 MB warning). **Project rule: no tracked file exceeds 50 MiB.** `scripts/verificar_tamanhos.py` (at the repository root) fails if one does, and the GitHub check runs it on every push. The largest data file of this edition is 0.04 MiB.

## 1. What this edition is, and is not

The International Edition is the region-neutral core. It ships **no regional rainfall database, no tariff catalogue, no cost catalogue and no emission-factor series**. It carries three worked examples (three cities, three rainfall series, three tariffs) so that the program opens with something to run. For a real project the user supplies:

| The user supplies | In the program | Without it |
| :--- | :--- | :--- |
| Daily rainfall series for the site (CSV, TXT or DAT; one value per line, in millimetres) | Climate source «own file» | the simulation cannot run |
| Water, sewer and electricity tariffs, in the currency of choice | Economic inputs | the economic analysis shows nothing |
| Costs (works, pump, treatment, maintenance) | Economic inputs | costs are zero, so payback and NPV say little |
| Grid emission factor and potable-water emission factor | Life-cycle inputs | the life-cycle assessment credits no avoided emissions |

## 4. Example tariffs (`examples/LEIA.md`)

The three example projects share one building and differ in city, currency and tariff. Prices were read from each utility's published tariff and entered as printed; the hand-checked bills (for 18 m³ per month) are US$ 88.08, £ 91.97 and R 1,252.32, and `tests/unit/test_exemplos_da_edicao.py` recomputes them.

| City | Utility and document | In force | Notes |
| :--- | :--- | :--- | :--- |
| New York | NYC Water Board and NYC DEP, Water and Sewer Rates, FY2027 | from 01/07/2026 | water US$ 5.35 per CCF; sewer 159% of the water charge; minimum charge US$ 0.49 per day |
| London | Thames Water, charges 2026-27, metered household | taken as 01/04/2026 (inferred) | water £ 2.7346 per m³; wastewater £ 1.4721 per m³; standing charges |
| Cape Town | City of Cape Town, Tariffs 2026/27, domestic, non-indigent | taken as 01/07/2026 (inferred) | stepped water and sanitation tariffs, VAT included |

- **Licence.** Published prices are facts; the utilities' documents are not redistributed. The licence of each utility's website was not checked.
- **Status: illustrative.** The tariffs are labelled as illustrative in `examples/LEIA.md`. Document URL and SHA-256 were **not recorded** when the examples were built, so the figures cannot be traced to a stored copy of the document. Not verified in this version: the URL, access date and SHA-256 of each document. Do not use them for a real project.
- **Quality.** Each tariff has been checked by hand against the printed bill, once. There is no independent second check. The effective dates for London and Cape Town are inferred and flagged in the example notes. Two assumptions to confirm are listed in `examples/LEIA.md` (minimum charge scope in New York; sewer volume basis in London).
- **Not set, on purpose.** Costs of works, pump, treatment and maintenance, the electricity tariff and the grid emission factor are zero or unset in the examples. No official source was used for them. Payback and NPV shown for the examples are therefore not results.

## 5. Core reference files

| File | What it is | Status in this edition |
| :--- | :--- | :--- |
| `triton/data/costs_database.json` | Reference-cost parameters used by the core | Neutral in this edition: every price is zero and there is no currency or regional factor; costs start at zero and the user enters their own |
| `triton/data/rotas_producao_agua.json` | Routes by which potable water is produced, with the emission avoided per m³ when rainwater replaces it | The avoided emission depends on the route replaced; the user declares it |
| `triton/data/fatores_emissao_rede_padrao.json` | Empty template | Grid factor is 0 until the user enters the factor for the project's grid |

## 6. Size limits and checks

- Limit: 50 MiB per tracked file. Largest file in this edition: `manual/en/Triton-User-Manual.pdf`, 6.51 MiB. Data files together: under 3 MiB.
- Check: `python scripts/verificar_tamanhos.py` (from the repository root) and `tests/unit/test_tamanho_dos_dados.py`.
- Adding your own large series: keep it outside the repository, or split it, so that no tracked file passes the limit.
