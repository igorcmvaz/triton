# Project files from the Manual (International Edition)

Each file reproduces a case study described in the manual. Open via **File > Open Project**, and click **Simulate**.

The rainfall series is embedded **inside** each file: it opens without needing the original CSV, on any computer.

| File | Section | Description | City / Context |
| :--- | :--- | :--- | :--- |
| `01_tutorial_new_york.triton` | Chapters 4 & 5 | Tutorial house with 150 m² roof, 4 residents, 4,000 L tank, DEP tariff | New York (ERA5 1991–2020) |
| `02_london.triton` | Section 3.1 | Tutorial building simulated under maritime temperate climate and Thames Water tariffs | London (ERA5 1991–2020) |
| `03_cape_town.triton` | Section 3.1 | Tutorial building simulated under Mediterranean/semi-arid climate and City of Cape Town stepped tariffs | Cape Town (ERA5 1991–2020) |
| `04_tutorial_sweep.triton` | Section 4.4 | Tank volume optimization sweep from 0 to 20,000 L in 1,000 L increments | New York (ERA5 1991–2020) |
| `05_ten_days.triton` | Section 2.1 | Didactic 10-day daily mass balance validation case (matching spreadsheet) | Educational benchmark |
